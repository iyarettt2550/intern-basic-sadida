หน้าของผู้ใช้
1 หน้าหลัก จะเป็นหน้าที่ประกอบด้วยรูปโลโก้ร้านไปเอารูปมาใส่ได้อยุ่ใน public/logo ชื่อแบนร์ sadida มีรูปแบรน์เนอร์ กับสิน้คารองเท้าแบบcard สามารถเลื่อนได้ โดยทำรูปแบบ grid เพื่อให้แอดมินหรอเจ้ามาสลับหรือแก้องค์ประกอบได้โดยไม่ต้องเขียนโค้ดมาแก้เอง
2 หน้าสินค้า มีประเภทสินค้าแค่ 2 ประเภท  รองเท้าวิ่ง รองเท้าเดิน ตามที่อยู่ในฐานข้อมูล
3 หน้าติดต่อเรา หน้านี้จะใว้สำหรับให้ inbox มาหา admin มีที่อยู่เป็น api google map 

หน้าแอดมิน
1 หน้า login ของแอดมิน กับ ของเจ้าของ ใว้สำหรับ login เข้าระบบหลังบ้าน
2 หน้า dashboard โชว์รายละเอียดต่างๆของหลังบ้าน
3 หน้าจัดการสินค้า ปกตทั่วไปมีเพิ่ม ดูรายละเอียดข้างในว่าอยู่ประเภทไหน ชื่อสินค้าอะไร ราคา ขนาด/ไซต์ ซึ่งไปดึงจากฐานข้อมูลได้เลย
4 หน้าติดต่อ หน้าที่ผู้ใช้ติดต่อเขามาสามารถกดดูเพื่อโชว์รายละเอียดต่างๆที่ผู้ใช้ทักมา
5 หน้าจัดการเว็ปไซต์ สามารถแก้หรือสลับองค์ประกอบแบบ grid ได้ แก้ชื่อ แก้รูปภาพได้ ซึ้งจะแก้ได้ 3 หน้า หน้าหลัง หน้าสินค้า หน้าติดต่อ
