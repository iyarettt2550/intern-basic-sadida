1 เพิ่มฐานข้อมูลสำหรับรองรับการแก้ไขหน้าเว็ปในส่วนของ adminwebsize เนื่องจากตอนdeployได้ทำการแก้ไขแล้วหน้าผู้ใช้ไม่อัพเดตวิธีมีประมาณนี้
    1. สร้างตารางใหม่ในฐานข้อมูล สร้างตารางฝห้ครอบครุมทั้ง 3 หน้าหลักของผู้ใช้พร้อมกับให้สามารถเก็บรูปภาพเป็นไฟล์ได้
(ใช้ประเภท JSONB ใน PostgreSQL จะสะดวกมาก เพราะสามารถเก็บ Object ของ Config ทั้งหมดได้โดยไม่ต้องแยกคอลัมน์ยิบย่อย)

    2. ทำ API เชื่อมต่อที่ Backend (Hono)
สร้าง 2 Endpoints ในเซิร์ฟเวอร์:

GET /api/website-config (Public): ให้หน้าเว็บฝั่งผู้ใช้ทั่วไปเรียกเพื่อดึงข้อมูลชื่อแบรนด์, โลโก้ และแบนเนอร์ล่าสุดไปแสดงผล
PUT /api/admin/website-config (Admin): สำหรับหน้าจัดการแอดมิน เมื่อกดปุ่ม "บันทึกการเปลี่ยนแปลง" ให้ยิงส่งข้อมูล { brand, pages } ไปอัปเดตลงฐานข้อมูล
    3. ปรับการทำงานที่ Frontend
ฝั่งอ่านข้อมูล (websiteConfig.ts): เปลี่ยนจากการอ่าน getCookie() / localStorage ให้เป็นการ fetch('/api/website-config') จากเซิร์ฟเวอร์
ฝั่งบันทึก (AdminWebsite.tsx): เมื่อกดเซฟ ให้ยิง fetch('/api/admin/website-config', { method: 'PUT', ... }) ลงฐานข้อมูล

2 แก้ไขฐานข้อมูลทั้งหมดที่เป็นรูปภาพ เป็นจากเก็บที่อยู่พาท ที่อยู่ไฟล์ เป็น เก็บไฟล์รูปจริงๆเข้าฐานข้อมูล

3 เพิ่มตัวปรับขนาดไฟล์รูปไม่ให้ใหญ่เกินไปเพื่อกันไม่ให้ตัวเว็ประเบิด ก่อนจะนำรูปภาพไปใช้งาน ให้เขียนฟังก์ชันย่อขนาด (Resize ด้วย HTML5 Canvas) เช่น ให้ขนาดภาพกว้างไม่เกิน 800–1200px และบีบอัดคุณภาพเหลือ 80% เพื่อลดขนาดไฟล์จากหลาย Megabytes ให้เหลือเพียงไม่กี่สิบ Kilobytes

4 ปรับฟอแมตเบอร์โทรด้วยกันคนใส่
